# Finlytics — AI-Powered Finance & Stock Analytics Toolkit

[![Python](https://img.shields.io/badge/python-3.10%2B-blue.svg)](https://www.python.org/)
[![Tests](https://img.shields.io/badge/tests-pytest-green.svg)](#testing)
[![License](https://img.shields.io/badge/license-see%20LICENSE-lightgrey.svg)](LICENSE)

**Finlytics** started life as a single-file APY calculator and has grown into a modular, professional finance toolkit. It still answers the original question — *"how much will my capital grow in a year, and in which currency?"* — but now adds a full **stock-analytics engine**, **portfolio analytics**, and an **AI/quant layer** with machine-learning forecasts, Monte-Carlo price projections and an optional LLM analyst.

> ⚠️ **Disclaimer:** Finlytics is an educational tool. Nothing it produces is financial advice. Markets are risky; do your own research.

---

## ✨ Features

| Area | What you get |
|------|--------------|
| 💰 **APY & compounding** | Compound-growth projections with arbitrary compounding frequency and recurring monthly contributions. Multi-currency comparison (EUR/USD/GBP) at **live FX rates**. |
| 💱 **Currency exchange** | Spot conversion and cross-rates via Yahoo Finance. |
| 📈 **Stock analysis** | OHLCV data, technical indicators (SMA, EMA, **RSI**, **MACD**, Bollinger Bands) and risk metrics (annualised return/volatility, **Sharpe**, **Sortino**, **max drawdown**, **beta** vs. benchmark). A composite **BUY / HOLD / SELL** signal with human-readable reasoning. |
| 🧺 **Portfolio analytics** | Weighted basket return & risk, correlation matrix, and per-asset **risk contributions**. |
| 🤖 **AI / quant forecasting** | ML next-day return model (scikit-learn Gradient Boosting, with a zero-dependency NumPy fallback) **and** a **Monte-Carlo** GBM projection with a 90% confidence band and probability-of-profit. |
| 🧠 **AI analyst (optional)** | A plain-English briefing generated by an LLM (Anthropic) when an API key is present — otherwise a deterministic rule-based narrative, so it always works. |
| 🖥️ **Clean CLI** | One `finlytics` command with subcommands, JSON output that's easy to pipe into other tools. |

## 🏗️ Architecture

```
finlytics/
├── config.py        # tunable defaults (risk-free rate, APYs, benchmark, LLM cfg)
├── data.py          # cached yfinance access layer + DataError handling
├── fx.py            # currency conversion & cross-rates
├── apy.py           # compound/APY projections + multi-currency comparison
├── indicators.py    # SMA, EMA, RSI, MACD, Bollinger, returns  (pure functions)
├── metrics.py       # return / volatility / Sharpe / Sortino / drawdown / beta
├── stocks.py        # StockAnalyzer: data + indicators + metrics + signal
├── portfolio.py     # weighted-basket risk/return analytics
├── ai/
│   ├── forecast.py  # ML forecaster + Monte-Carlo projection
│   └── insights.py  # LLM analyst with rule-based fallback
└── cli.py           # argparse CLI (apy / fx / stock / forecast / portfolio / analyze)
```

The data layer is the only component that touches the network, so every
indicator and metric is a pure function that's fast and unit-testable offline.

## 🚀 Installation

```bash
git clone https://github.com/kpassiasGit/APYcalculator-finance.git
cd APYcalculator-finance

# Core install (yfinance, pandas, numpy)
pip install -e .

# Recommended extras:
pip install -e ".[ml]"      # scikit-learn — stronger ML forecaster
pip install -e ".[ai]"      # anthropic    — LLM natural-language analyst
pip install -e ".[all]"     # everything, including pytest + matplotlib
```

> The toolkit runs with just the core dependencies. `scikit-learn` and
> `anthropic` are **optional** — Finlytics automatically falls back to a NumPy
> model and a rule-based narrative when they're absent.

### Configuration (optional)

All defaults can be overridden via environment variables:

| Variable | Purpose | Default |
|----------|---------|---------|
| `FINLYTICS_RISK_FREE` | Risk-free rate for Sharpe/Sortino | `0.03` |
| `FINLYTICS_BENCHMARK` | Benchmark ticker for beta | `^GSPC` |
| `FINLYTICS_APY_USD/EUR/GBP` | Default APYs (%) | `5.05 / 3.85 / 5.12` |
| `ANTHROPIC_API_KEY` | Enables the LLM analyst | _(unset)_ |
| `FINLYTICS_LLM_MODEL` | LLM model name | `claude-opus-4-8` |

## 🖥️ Web interface (easiest way to start)

Finlytics ships with a clean, modern single-page UI — tabs for **Analyze,
Stock, Forecast, Portfolio, APY and FX**, with live price sparklines, metric
cards, a BUY/HOLD/SELL badge and the AI briefing.

```bash
pip install -e ".[web]"      # fastapi + uvicorn

```

## 🧑‍💻 Command-line usage

Finlytics is also driven by subcommands and prints JSON.

### APY & compounding

```bash
# Grow 1,000 at 5.05% APY for 1 year, adding 50/month
finlytics apy 1000 --apy 5.05 --years 1 --monthly 50

# Compare keeping 1,000 EUR in EUR vs USD vs GBP at live FX rates
finlytics apy 1000 --currency EUR --compare
```

```jsonc
{
  "principal": 1000.0,
  "apy_percent": 5.05,
  "years": 1.0,
  "contributions": 600.0,
  "final_value": 1666.13,
  "profit": 66.13
}
```

### Currency conversion

```bash
finlytics fx 500 USD EUR
```

### Stock analysis

```bash
finlytics stock AAPL --period 1y
```

Returns the last price, risk metrics, indicator readings and a signal:


### Portfolio analytics

```bash
finlytics portfolio AAPL MSFT GOOG --weights 0.5 0.3 0.2 --period 1y
```

### Full analysis with an AI briefing

```bash
finlytics analyze TSLA --period 2y --horizon 30
```

Combines the stock analysis, ML forecast and Monte-Carlo projection, then adds a
natural-language `ai_briefing` (LLM-written if `ANTHROPIC_API_KEY` is set,
otherwise rule-based).

### Use it as a library

```python
from finlytics.stocks import StockAnalyzer
from finlytics.ai.forecast import Forecaster, monte_carlo

analysis = StockAnalyzer().analyze("AAPL", period="1y")
print(analysis.signal, analysis.metrics["sharpe"])

close = analysis.history["Close"]
print(Forecaster().fit_predict("AAPL", close).summary())
print(monte_carlo("AAPL", close, horizon_days=30).summary())
```

## 🔬 How the AI layer works

1. **Feature engineering** — lagged returns (1/2/3/5/10-day), price-to-SMA
   ratios, RSI and rolling volatility are computed from closing prices, with the
   next-day return as the supervised target (no look-ahead leakage).
2. **Model** — a `GradientBoostingRegressor` is trained on a chronological
   train/test split; if scikit-learn isn't installed a NumPy least-squares model
   is used instead. The toolkit reports out-of-sample R² and directional
   accuracy so you can judge the signal honestly.
3. **Monte-Carlo projection** — daily log-returns drive a Geometric Brownian
   Motion simulation (10,000 paths by default), yielding an expected price,
   median, 90% confidence band and probability of finishing in profit.
4. **Narrative** — metrics + forecast are summarised into a readable briefing,
   by an LLM when configured or a deterministic template otherwise.

> Short-horizon return prediction is genuinely hard — expect R² near zero and
> directional accuracy near 50%. Finlytics surfaces these numbers on purpose
> rather than overselling the model.

## 🛠️ Troubleshooting

**`No data returned` / `CERTIFICATE_VERIFY_FAILED` / empty history**

- Make sure you're on a **recent `yfinance`** (`pip install -U yfinance`). Older
  pinned versions (e.g. `0.2.35`) no longer work against Yahoo's API.
- Behind a **corporate TLS-intercepting proxy**, install the proxy extra so TLS
  is verified through your OS trust store:
  ```bash
  pip install -e ".[proxy]"   # adds `truststore`, injected automatically
  ```
  `yfinance`'s `curl_cffi` backend uses libcurl, so if it still fails, point it
  at a CA bundle that includes your proxy's root certificate:
  ```bash
  export CURL_CA_BUNDLE=/path/to/combined-ca.pem   # Windows: set CURL_CA_BUNDLE=...
  ```
